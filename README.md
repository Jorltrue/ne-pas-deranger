# Ne pas déranger · l'atelier ordinateur

Escape game pédagogique pour l'hôtellerie-restauration (niveau CAP). Ce dépôt contient l'atelier « Le poste de
réception » : le logiciel de l'hôtel Le Belvédère, son site Internet et les missions des brigades.

**Jouer : https://jorltrue.github.io/ne-pas-deranger/**

- Tout le jeu tient dans `index.html`. Il marche aussi sans Internet : téléchargez le fichier et ouvrez-le d'un double-clic.
- Les bonnes réponses ne sont pas écrites en clair : la page ne contient que leurs empreintes SHA-256.
- Les dossiers papier du jeu (élèves, enseignant, mise en place) ne sont pas publiés ici.
